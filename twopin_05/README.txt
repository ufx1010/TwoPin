中英文單字配對遊戲 — 基本 2000 字與常用 200 句版 (twopin_05)
=============================================================

這是一個強大的中英文雙語配對記憶遊戲，整合了「基礎英文 2000 單字」以及「生活常用 200 句句型」，是款兼具深度與靈活度的英語學習平台。

📋 核心功能與特色說明
---------------------
1. 多維度單字篩選系統：
   - 字母開頭篩選：可以一鍵篩選特定字母（A-Z）開頭的單字。
   - 單字難易度分類：
     * 易：1–4 個字母的簡單單字。
     * 中：5–7 個字母的中等單字。
     * 難：8 個字母以上的挑戰單字。
   - 音節數篩選：支援篩選「單音節」、「雙音節」、「三音節」單字進行專項發音與重音特訓。

2. 生活常用 200 句整合：
   - 除了單字外，還收錄了常用對話與問候語（如：Hello, How's it going?, My pleasure 等），完美融入口語與對話配對。

3. 語音輸入辨識 (🎤) 與 TTS：
   - 語音比對模式：除了手動點擊卡牌配對，本遊戲支援用語音輸入（麥克風錄音辨識）來進行配對，即時練習口語。
   - 每個單字在點選時皆會觸發高品質 TTS 音訊播放，加強聽覺記憶。

4. 自訂面板與介面選項：
   - 支援 6, 12, 21 對等多種卡牌數量設定。
   - 提供 9 種精美英文字型及獨立的中英文滑桿式字級大小調整。
   - 支援複製貼上自訂列表。

🛠️ 使用技術棧
--------------
- 原生 JavaScript (Vanilla JS)
- Web Speech API (SpeechSynthesis 朗讀與 SpeechRecognition 語音辨識比對)
- CSS Grid 響應式佈局
- Google Fonts & Custom CSS Variables
