我的歌詞本 — 英文五個元音高亮電子歌詞本 (twopin_song)
===================================================

這是一個優雅、輕量且實用的個人電子歌詞筆記本，具有英語五個元音字母專利色彩高亮顯示功能，專門用來跟讀與練習外語歌曲的腔調。

📋 核心功能與特色說明
---------------------
1. 五個元音 (vowel) 特色高亮：
   - 自動識別並對英文歌詞中的五個母音字母（A, E, I, O, U）著以高飽和、高對比的色彩（A 紅、E 綠、I 藍、O 橘、U 紫）。
   - 該設計能讓跟讀練習者更敏感地注意母音發音長度與腔調。

2. 歌詞筆記與編輯：
   - 內建優雅的歌詞卡片，支援點選行進行標註。
   - 內建歌詞編輯彈出視窗（Modal），支援隨時新增歌詞、編輯既有內容、或快速刪除不想要的歌曲。

3. 資料本地持久化：
   - 歌詞與歌曲清單自動保存至瀏覽器的 localStorage 中，即便關閉瀏覽器，再次開啟依舊完美保留所有修改。

4. 備份與一鍵恢復：
   - 支援將全部自訂的歌詞一鍵導出為一個備份 JSON 檔案。
   - 支援讀取該備份 JSON 檔案以快速恢復，方便在不同的裝置間同步。

🛠️ 使用技術棧
--------------
- 原生 JavaScript (Vanilla JS)
- HTML5 LocalStorage API (資料持久化)
- RegExp 著色引擎 (利用正則表達式快速為特定字母添加 CSS styling)
- CSS Custom Variables & Beautiful CSS Transitions
