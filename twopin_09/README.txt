畫中有詩篇 — 詩詞壁紙與書法排版工具 (twopin_09)
==============================================

這是一個將優美的背景圖片與精緻文字書法排版完美結合的創意畫布工具。最適合用來製作古典詩詞卡片、禪意壁紙、節日賀卡或個人金句圖檔。

📋 核心功能與特色說明
---------------------
1. 強大的背景設定：
   - 支援選擇純色背景或漸層色背景。
   - 支援拖曳上傳或點選載入本地端的高畫質圖片作為背景底圖。

2. 多維度排版調整：
   - 直書/橫書自由切換：一鍵將文字切換為「橫排」或「直排」，適配中日古典美學。
   - 文字對齊：提供置左、置中、置右、分散對齊等。
   - 參數滑桿：字體大小、內文大小、行距（Gap）、字體行高（Line Height）均可無級微調。

3. 精緻視覺控制與文字拖拽：
   - 使用者可在畫布（Canvas）中以滑鼠或觸控直接拖拽文字區塊，精準定位其在圖片中的位置。
   - 支援文字陰影、半透明度、自訂文字顏色調色盤。

4. 匯出下載：
   - 一鍵將排版完畢的精美畫面渲染並匯出下載為高品質的 PNG 格式圖片。

🛠️ 使用技術棧
--------------
- 原生 JavaScript (Vanilla JS)
- HTML5 Canvas API (動態渲染文字、陰影、背景圖片並進行合成)
- File Reader API (本地端圖片與文字即時讀取載入)
- CSS Flexbox 響應式佈局
