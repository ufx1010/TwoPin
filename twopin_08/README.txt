Bug-free 文字編輯器 (twopin_08)
=============================

這是一個針對純文字（.txt）編輯、美化排版及直書橫書轉換設計的高效網頁文字編輯器，特別著重於閱讀舒適性與靈活的視覺呈現。

📋 核心功能與特色說明
---------------------
1. 直書/橫書與排版自由切換：
   - 支援將文字流一鍵切換為「橫排（由左至右）」或「直排（由右至左，由上至下）」書寫，非常適合進行書法文稿、詩詞創作或繁體中文長篇閱讀。
   - 支援文字對齊方式：置左、置中、置右、分散對齊。

2. 豐富的視覺客製化選項：
   - 字級大小（12px - 72px）與行距（10px - 100px）滑桿無級調節。
   - 字體行高調節，確保每行文字間具有最完美的呼吸空間。
   - 精準的配色選擇器：可自由設定「文字顏色」與「背景底色」，營造最舒適的護眼暗黑模式或復古宣紙風格。

3. 檔案開啟與匯出儲存：
   - 一鍵將目前編輯內容匯出下載為標準純文字檔案（.txt）。
   - 支援點選或拖入本地 `.txt` 檔案進行即時載入編輯。

4. 寫作與閱讀統計：
   - 自動即時統計總字數與行數，最適合文案工作者、學生與小說創作者。

🛠️ 使用技術棧
--------------
- 原生 JavaScript (Vanilla JS)
- CSS Writing Mode (用於實現無縫的直書橫書排版)
- HTML5 File System API & Blob API (純文字檔案載入與匯出下載)
- CSS Custom Properties (網頁樣式動態自訂)
