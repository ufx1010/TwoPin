中英文綜合打字練習系統 (twopin_E)
================================

這是一個高度整合中英文雙語的綜合打字與口語/聽力綜合訓練系統，具備靈活的文章選擇與細緻的數據統計，是打字愛好者與語言學習者的首選。

📋 核心功能與特色說明
---------------------
1. 中英雙重練習模式：
   - 支援純英文、純中文以及中英混合文章打字練習。
   - 同步支援中文 IME 輸入法的防組字打斷機制，保障選字比對完美精準。

2. TTS 伴讀與語音反饋：
   - 輸入的同時會調用 Web Speech 語音引擎即時用語音朗讀當前輸入的單字或字句，加深印象。
   - 支援快速靜音或語速調節。

3. 專業級監控與進度反饋：
   - 細緻統計：即時顯示打字速度（每分鐘字數）、精準度（%）、錯誤字符統計。
   - 配置亮眼的可視化打字進度條，隨時了解打字文章的完成百分比。

4. 自訂文章素材：
   - 使用者可隨時拷貝或拖入自訂的 `.txt` 文章做為練習素材，一鍵加載即刻開始打字。

🛠️ 使用技術棧
--------------
- 原生 JavaScript (Vanilla JS)
- Web Speech API (Bilingual SpeechSynthesis 雙語發音)
- Keydown / Composition Events (高精度键盘與輸入法狀態捕獲)
- HTML5 File Reader API & Blob API
- Responsive UI Design & Progress Bars
