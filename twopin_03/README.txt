單字配對遊戲 — aeiou 短母音專題版 (twopin_03)
============================================

這是一個特別針對英語自然發音「aeiou 短母音」設計的單字配對挑戰遊戲，幫助學習者打好自然發音基礎。

📋 核心功能與特色說明
---------------------
1. aeiou 短母音主題單字庫：
   - 預裝 aeiou 常用短母音單字，如 cat (貓)、bat (蝙蝠)、bed (床)、pet (寵物)、pig (豬)、wig (假髮) 等。
   - 單字中的元音字母（a, e, i, o, u）在卡牌上會被賦予獨特的亮眼顏色（a 紅、e 綠、i 藍、o 橙、u 紫）進行高亮顯示，加深學習者對拼讀規則的直覺認知。

2. 遊戲設定與自訂選項：
   - 支援 6 對、12 對、21 對卡牌配對挑戰。
   - 支援 9 種多樣英文字型（手寫、圓潤、系統、現代、像素風格等）的即時切換。
   - 提供字體大小無級滑桿調節。

3. 自訂卡片內容：
   - 支援使用者輸入自訂單字，格式為 `中文 | 英文 | [音標/注音]`，系統會自動解析並將其融入配對卡牌。

4. 語音朗讀與動態補充：
   - 點擊卡片時系統會調用 TTS 自動進行英文單字朗讀，輔助拼讀和聽力。
   - 採用動態卡牌補充機制，配對成功後會自動補充新牌，確保遊戲挑戰不間斷。

🛠️ 使用技術棧
--------------
- 原生 JavaScript (Vanilla JS)
- Web Speech API (SpeechSynthesis 語音朗讀)
- CSS Variables / Custom Properties (用於動態更換英文字型與字級)
- Responsive Grid Layout & CSS CSS Keyframe Animations
