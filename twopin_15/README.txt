藝術裱框 (Calligraphy Frame Tool)
========================================

【功能簡介】
本應用程式為高質感的書法作品藝術裱框與排版工具，專為古典書法、現代詩詞與藝術創作設計。使用者可自由輸入與排版文字、選用多款中文字型與藝術效果，並搭配多樣化的框材、黃銅包角、漸層底紙與自訂背景，最終導出高清無損的作品圖片。

【技術架構】
- HTML5 / CSS3 (Flexbox & Glassmorphism 現代暗黑美學介面)
- Tailwind CSS 樣式庫與 Google Fonts (思源宋體、思源黑體、馬善政楷書、龍藏體、志莽行書、小薇體等 12 款精選字型)
- Vanilla JavaScript (無框架設計，高效原生 DOM 互動)
- html2canvas 1.4.1 (高解析度 DOM 轉 Canvas 圖片導出)

【主要功能與操作說明】
1. 文字內容編輯 (內容頁籤)：
   - 支援輸入標題與正文（自動換行與手動換行）。
   - 可點擊「➕ 新增文字」自由新增自訂文字區塊，隨意拖曳定位。
   - 點擊「🗑️ 刪除選中」快速清除當前選中的文字區塊。

2. 細節排版與書法特效 (排版頁籤)：
   - 一鍵切換直排 (vertical-rl) 與橫排 (horizontal-tb) 排版方向。
   - 支援文字大小、字距、行距、旋轉角度、欄寬與欄高精確微調。
   - 多色漸層效果：提供單色與 3 色線性漸層角度微調，並內建墨黑、硃紅、金箔、青綠、水墨等多款預設色彩組合。
   - 12 款書法文字特效：飛白、暈染、焦墨、雙鉤、水墨、印白、裂紋、拓印、霓虹、焰火、冰封等。

3. 裱框與底紙樣式 (裱框頁籤)：
   - 畫布比例切換：原比 (270x405)、1:1 正方、4:5 小紅書、3:4 直幅、9:16 限動、16:9 橫幅、3:2 與 2:3。
   - 8 種高級外框材質：紅木、鎏金、玄檀、縷空、浮雕框、石質、金屬、玉質。
   - 經典黃銅包角：可開關包角裝飾並調整包角尺寸。
   - 底紙圖片上傳：支援自訂底圖圖片上傳、置中、填滿、適應與透明度調整。
   - 包皮、裱框與底紙三層漸層色彩自訂與隨機生成。

4. 響應式介面與圖片導出：
   - 具備預覽畫布動態自動適應縮放 (Auto-Fit)，確保手機端與 GitHub Pages 執行時控制面板與功能鍵皆能完整顯示且不被擠出視窗。
   - 支援 PNG (透明高清)、JPG (白底小檔) 與 WEBP (高壓縮) 多種導出格式，並可自訂 2x/3x/4x 解析度與畫質。
