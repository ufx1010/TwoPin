中文輸入練習工具 (twopin_D)
==========================

這是一個專門為了提升中文鍵盤輸入速度（字數/分鐘）與組字精準度而設計的互動式中文打字訓練應用。特別針對中文 IME 輸入法在網頁事件中的特殊性進行了優化。

📋 核心功能與特色說明
---------------------
1. 針對中文輸入法 (IME) 特化設計：
   - 完美處理中文輸入時的「注音/拼音組字階段（Composition Events）」，避免在選字未完成前觸發錯誤字元比對，確保極致順暢的打字體驗。

2. 即時數據反饋：
   - 即時計算並顯示打字速度（每分鐘字數）、正確率（%）、錯誤次數及練習計時器。

3. 語音朗讀與聽寫：
   - 點選或輸入單字時自動播放中文 TTS 讀音，強化聽力、讀音與鍵盤打字肌肉記憶的連結。

4. 舒適的深色護眼界面：
   - 採用清爽現代的暗色系界面，極大減輕長時間練習打字對眼睛造成的疲勞。

🛠️ 使用技術棧
--------------
- 原生 JavaScript (Vanilla JS)
- Web Composition Events (compositionstart, compositionupdate, compositionend - 處理 IME 選字與組字邏輯)
- Web Speech API (SpeechSynthesis 中文發音引擎)
- CSS Flexbox 響應式佈局
