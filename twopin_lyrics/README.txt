LRC 🔄 SRT 🔄 JSON 歌詞與字幕格式轉換工具 (twopin_lyrics)
======================================================

這是一個專業高效的歌詞與字幕格式互轉與時間軸編輯工具。專為影音創作者、翻譯人員、字幕組及語言學習者打造，提供毫秒級的時間處理與批量操作。

📋 核心功能與特色說明
---------------------
1. 格式無縫三向互轉：
   - 支援 LRC 歌詞（標準時間標記格式）、SRT 影片字幕檔及 LinguaBook 專屬的 JSON 格式之間進行極速批量轉換。

2. 批量時間軸偏移調整 (Offset)：
   - 支援對所有時間戳記進行毫秒級或秒級批量延遲或提前（Delay/Speed up）。例如輸入 `1.5` 即可讓整首歌詞字幕延後 1.5 秒，是解決影音不同步的最強利器。

3. 中文翻譯與顯示控制：
   - 可一鍵選擇「是否匯入/匯出中文翻譯」進行雙語字幕整合。
   - 支援「隱藏時間」選項，快速提取出純文字歌詞，方便排版。

4. 便捷的檔案操作：
   - 支援拖曳或上傳檔案進行轉換。
   - 提供即時轉換預覽窗口，一鍵點選即可將轉換後的結果下載為對應的標準格式檔案（.lrc, .srt, .json）。

🛠️ 使用技術棧
--------------
- 原生 JavaScript (Vanilla JS)
- Regular Expressions (高精度的時間戳與格式字串的正則表達式解析)
- HTML5 File Reader API & Blob / URL API (用於本地讀寫與生成下載鏈接)
- CSS Flexbox 響應式佈局
