🐒 輸入法 — 常用詞組快速輸入工具 (twopin_07)
===========================================

這是一個專為提升日常重複性文字回覆、客服快捷短語及範本快速管理而設計的「常用短語快捷鍵盤與輸入工具」。藉由將常用的字句或常用詞組保存為詞條卡片，一鍵點選即可快速複製或輸入。

📋 核心功能與特色說明
---------------------
1. 一鍵點選複製：
   - 畫面列出儲存的所有快捷詞條，輕觸或點選即可瞬間複製到系統剪貼簿中，並伴隨 Toast 彈窗提示。

2. 拖曳排序 (Sortable)：
   - 整合 SortableJS 函式庫，支援直接在畫面上拖曳各個詞條卡片，輕鬆自訂快捷排序與結構。

3. 語音輸入辨識 (🎤)：
   - 內建 Web Speech 語音識別功能。按下語音按鈕即可說話，自動將語音轉換為文字並追加到輸入框中。

4. 匯入、匯出與儲存：
   - 支援將自訂的快捷詞條資料導出為 `.monkey` 專屬格式的備份檔案。
   - 支援選擇 `.monkey` 備份檔，一鍵還原所有自訂快捷語。
   - 支援將編輯完的清單寫入本地資料庫持久化保存。

🛠️ 使用技術棧
--------------
- 核心框架：Vue 3 (採用 CDN Global Build)
- 樣式庫：Tailwind CSS v4 (極簡、現代感暗色系 UI)
- 拖曳技術：SortableJS
- 原生 APIs：
  * Web Speech API (SpeechRecognition 語音辨識)
  * LocalStorage / IndexedDB 本地儲存
  * Clipboard API 一鍵複製
