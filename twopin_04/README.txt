1自動翻譯機 — 基礎 850 字單字配對遊戲 (twopin_04)
==============================================

這是一個將基礎英語 850 個必備字彙（Basic English 850）與卡牌配對、發音學習結合的自動翻譯與記憶訓練應用。

📋 核心功能與特色說明
---------------------
1. 基礎英語 850 詞庫：
   - 預裝 Basic English 850 最核心的單字，並為每個單字配置了 KK 音標、中文翻譯以及對應的趣味 Emoji 插圖。
   - 單字內的元音（A, E, I, O, U）會特別進行高亮著色，輔助英文拼音和記憶。

2. 卡牌配對學習：
   - 玩家可選擇單局配對 6 對、12 對或 21 對單字。
   - 配對成功後，卡牌會以綠色高亮反饋並進行動態移出，接著補充新卡牌。

3. 自訂字型與介面調整：
   - 支援 9 種不同英文字體切換（包含多款獨具特色的手寫字型與圓潤黑體）。
   - 中英文本字級大小可通過滑桿獨立調整，確保不同設備、不同視力的用戶都有最佳體驗。

4. 發音伴讀與自訂題庫：
   - 內建 TTS 語音發音。
   - 用戶可透過底部的自訂文本框，自由貼上自己的詞彙對 `中文 | 英文 | [音標]` 進行額外主題練習。

🛠️ 使用技術棧
--------------
- 原生 JavaScript (Vanilla JS)
- Web Speech API (SpeechSynthesis)
- CSS Flexbox / Grid & Keyframes Animations
- Google Fonts API
