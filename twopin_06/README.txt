英語常用 400 句配對挑戰遊戲 (twopin_06)
======================================

這是一個專門為了精通「英語常用生活短句」而設計的句型配對學習遊戲，特別適用於日常英語口語速成與短句熟練度訓練。

📋 核心功能與特色說明
---------------------
1. 英語常用 400 句庫：
   - 內建生活交際、問候、自我介紹等豐富主題的 400 個標準短句。
   - 英文句子高亮顯示元音，並在配對成功或點擊時，由發音引擎進行標準語速朗讀。

2. 靈活的自訂題庫機制：
   - 完美相容並預載了「自訂題庫.txt」的內容。
   - 使用者可以隨時在底部的自訂區塊內粘貼自己的學習句型或詞彙。

3. 多元化配置與視覺：
   - 提供 6、12、21 對卡牌模式，適合不同難度與學習進度。
   - 具有 9 種字型風格切換（手寫風格到現代標準系統黑體）。
   - 中英文本字級大小可由獨立的滑桿分開設定，介面完美適配各尺寸屏幕。

🛠️ 使用技術棧
--------------
- 原生 JavaScript (Vanilla JS)
- Web Speech API (TTS 語音播報)
- CSS Animations (配對正確、配對錯誤與動態卡牌補充動畫)
- CSS Grid & Flexbox 響應式排版
