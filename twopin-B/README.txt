LinguaBook — 單曲版影音學習系統 (twopin-B)
========================================

這是一個專門為了精讀與同步單首歌曲/影片而設計的 LinguaBook 極簡實用版本，省去了繁雜的列表，更適合快速針對特定單曲進行歌詞同步、編輯、跟讀與本地備份。

📋 核心功能與特色說明
---------------------
1. 影片與音訊播放同步：
   - 支援拖曳本地音檔、影片進行播放，畫面完美同步。
   - 歌詞顯示具備高亮進度跟隨，並可拖曳時間軸進度。

2. 強大的雙語歌詞編輯功能：
   - 支援「區塊模式」逐行打點（提供 [mm:ss] 時間格式）以及「文本模式」自動排版、斷字。
   - 內建輔助小鍵盤，一鍵插入目前播放時間，實現極速字幕編輯。

3. 文字轉語音與輔助聽力：
   - 整合 TTS (Text-to-Speech) 引擎，可直接朗讀目前段落，並支援語速無級調整（0.5x 至 1.5x）。
   - 適合跟讀練習與聽寫特訓。

4. 手勢控制與螢幕適配：
   - 支援全螢幕顯示。
   - 播放畫面/圖片支援觸控手勢：雙指捏合縮放（0.3x 至 4x 縮放）、單指任意拖拽位置、雙擊重置回原狀。
   - 字幕可獨立浮動拖拽。

5. 本地儲存與轉換：
   - 資料自動寫入本地 IndexedDB，防止瀏覽器重新整理後編輯進度遺失。
   - 支援一鍵將整首歌備份為 JSON 格式，或單獨匯出標準 LRC 歌詞檔。

🛠️ 使用技術棧
--------------
- 原生 JavaScript (Vanilla JS)
- Tailwind CSS 樣式排版（暗黑極簡主義）
- HTML5 Video/Audio APIs
- Web Speech API (TTS 文字轉語音)
- IndexedDB (資料持久化儲存)
- Fullscreen API & Pointer Events (觸控捏合縮放手勢)
