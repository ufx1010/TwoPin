多國語言單字配對遊戲 — 坦米爾語版 (twopin_02)
==============================================

這是一個將中文字詞與坦米爾語（Tamil，坦米爾文）結合的拼寫與發音配對記憶遊戲，旨在幫助學習者趣味學習坦米爾語單字。

📋 核心功能與特色說明
---------------------
1. 雙語配對記憶遊戲：
   - 經典卡牌配對機制：卡牌一字排開，一邊為中文字詞（附帶 Emoji 插圖），另一邊為坦米爾語。
   - 點擊卡牌會翻開並高亮，配對成功時卡牌消除或標示為正確，並伴隨視覺動畫。

2. 內建豐富詞庫與類別：
   - 預載超過 100 組常用單字，涵蓋動物（貓、狗、熊）、食物（蘋果、麵包）、自然（太陽、月亮）、交通工具（汽車、火車）、家居（房子、椅子）以及學校、人體部位、服飾、醫院等豐富生活範疇。
   - 自訂題庫：提供輸入框，允許使用者貼上自訂列表，格式為 `中文名稱 | 坦米爾文 | [注音/發音]`。

3. 自訂選項與客製化：
   - 多種字型與外觀調整：提供 9 種英文手寫/圓潤/現代字型切換。
   - 字級調節滑桿：中英文的字體大小可分別獨立調大或縮小，以利長輩或孩童閱讀。
   - 單局卡片組數可選擇 6 對、12 對或 21 對。

4. 聽力與語音朗讀輔助 (TTS)：
   - 點擊卡片時自動使用 TTS 文字轉語音功能播放發音，一邊玩遊戲一邊掌握單字標準讀音。

5. 響應式佈局：
   - 全屏響應式網格（行動端自動排為 3 列，桌面端 4 列），並配備極佳的視覺交互回饋。

🛠️ 使用技術棧
--------------
- 原生 JavaScript (Vanilla JS)
- Web Speech API (SpeechSynthesis 語音朗讀)
- CSS Animations & Responsive Flex/Grid Layout
- Google Fonts (整合多款手寫與英文字體)
