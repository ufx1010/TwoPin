英文打字練習工具 (twopin_C)
==========================

這是一個專門為了提升英打速度（WPM）與鍵盤輸入精準度（Accuracy）而設計的互動式英文打字特訓應用。

📋 核心功能與特色說明
---------------------
1. 即時打字監控與統計數據：
   - 即時計算並顯示打字速度：WPM (Words Per Minute，每分鐘字數)。
   - 即時精準度（Accuracy %）與錯字（Errors）數量計數。
   - 伴隨計時器紀錄練習總用時。

2. 智慧高亮與視覺引導：
   - 單字逐字高亮：當前需要輸入的單字會特別標出。
   - 字母級糾錯回饋：正確輸入的字母呈現鮮明綠色，打錯的字則會高亮呈紅色，提示玩家立即修正。

3. 多樣化練習素材：
   - 內建精選英文短文、常用句子與基礎單字段落。
   - 支援使用者上傳自訂英文文章進行客製化特訓。

4. 語音朗讀伴讀 (TTS)：
   - 打字時可開啟/關閉 TTS，輸入時自動播報英文語音，提高聽力與打字手感的聯動。

🛠️ 使用技術棧
--------------
- 原生 JavaScript (Vanilla JS)
- Web Keydown / Keyboard Events (極速捕獲並比對按鍵字元)
- Web Speech API (SpeechSynthesis 英文發音伴讀)
- CSS Flexbox 響應式佈局與現代暗色主題
