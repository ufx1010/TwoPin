LinguaBook — 雙語影音歌詞學習系統 (twopin-A)
==============================================

這是一個專門為了自學外語歌曲、發音練習及雙語影音字幕同步與管理而設計的完整全方位 Web 應用程式。

📋 核心功能與特色說明
---------------------
1. 媒體播放與同步：
   - 支援本地音檔、影片、圖片多媒體播放。
   - 歌詞與多媒體播放進度時間軸高度同步顯示，並支援隨時拖曳進度條控制播放。
   - 提供播放清單前後曲導航。

2. 雙語歌詞編輯器：
   - 區塊模式：逐行編輯歌詞，並帶有精準的 [mm:ss] 時間標記。
   - 文本模式：純文字輸入，支援自動格式化處理。
   - 智能分詞：支援日文/中文逐字、英文與其他外語按單字進行斷詞高亮。
   - 配備時間戳快速設定虛擬小鍵盤，大幅提升打點效率。

3. 語音合成與朗讀 (TTS)：
   - 自動語音語言偵測（支援英文、中文、日文、韓文、阿拉伯文、坦米爾文等多國語言）。
   - 可在 0.5x 至 1.5x 之間靈活調節語速。
   - 支援原文與譯文聲音的獨立開關控制。

4. 互動發音練習模式 (🎤)：
   - 語音辨識技術：使用 Web Speech API 進行即時錄音並辨識使用者的發音。
   - 容錯度可調：提供 1% - 100% 辨識嚴格程度調整。
   - 即時反饋：以高亮顏色在畫面上清晰標示正確與錯誤的部分。
   - 手動練習：無麥克風時可切換為打字練習模式。

5. 快速打點同步功能 (⏱️)：
   - 邊放音樂邊點擊字幕，系統自動記錄該行歌詞的精準時間點，適合全新歌詞製作。

6. 進階歌曲與資料管理：
   - 整合 IndexedDB 本地資料庫儲存音樂、影片、圖片及歌詞，確保離線可用且多首歌曲獨立保存。
   - 支援新增、刪除、自訂拖拽、排序（A-Z, Z-A, 最新/最舊）歌曲清單。
   - 多分頁數據自動同步，保障編輯進度不遺失。

7. 匯入與匯出：
   - 匯出/匯入單曲 JSON 備份檔案，方便移機與備份。
   - 匯出標準 LRC 歌詞格式（原文/譯文分開匯出）。
   - 支援將媒體字幕與 Canvas 合成匯出完整視訊影片。

8. 字型、外觀與手勢客製化：
   - 字體大小滑桿式微調、多色主題選色。
   - 支援隱藏網址列之全螢幕沉浸式模式。
   - 觸控手勢操作：影片與圖片支援雙指捏合縮放（0.3x - 4x）、單指拖曳、雙擊還原。

🛠️ 使用技術棧
--------------
- 核心語言：原生 JavaScript (Vanilla JS - 無外部框架依賴)
- 樣式框架：Tailwind CSS (響應式深色主題與 Glassmorphism 玻璃態效果)
- 瀏覽器原生 APIs：
  * Web Audio API (音訊流抽取與合成)
  * Web Speech API (TTS 文字轉語音、SpeechRecognition 語音辨識)
  * IndexedDB (大容量本地快取儲存)
  * Canvas API & WebRTC MediaRecorder (側邊影片/字幕錄製)
  * Fullscreen API (全螢幕控制)
